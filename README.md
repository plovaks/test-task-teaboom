# Верстка крточки товара для магазина чая

## Стек
- **HTML**
- **CSS**
- **JavaScript**

## Запуск локальный

1. Загрузить все файлы и папку с фотографиями
2. Открыть index.html в браузере

## Адаптивная верстка

Адаптивная верстка была реализована с помощью медиа-запросов
Карточка корректно отображается на десктопных, мобильных устройствах, планшетах
Брейкпоинты: 960px, 640px
